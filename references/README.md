# Códigos Originais de Referência (Receita Federal)

Este diretório armazena os repositórios/códigos-fonte originais oficiais da Receita Federal (Java/Go) **exclusivamente para consulta de regras de negócio** durante a migração para Python/FastAPI.

> **Regra de Git Flow:** Os fontes originais devem ser mantidos intactos na branch `originals`. Nenhuma alteração de código Python deve ser feita dentro de `references/`.

## Módulos

- `references/simples/` -> `https://github.com/ReceitaFederal/calculadora-rtc-simples-nacional`
- `references/regime-regular/` -> `https://github.com/ReceitaFederal/calculadora-rtc-regime-regular`
- `references/danfse/` -> `https://github.com/ReceitaFederal/calculadora-rtc-gerador-danfse`
